FACTORIAL PROGRAM
 
AIM
To write a Python program to calculate the factorial of a given number.
 
DESCRIPTION
The factorial of a number is the product of all positive integers from 1 up to that number. It is widely used in mathematics, especially in permutations, combinations, and probability calculations. This program takes a number as input and computes its factorial using a loop.
 
FORMULA
n! = n x (n - 1) x (n - 2) x ... x 2 x 1
Special case: 0! = 1
 
INPUT
Enter a number: 5
 
OUTPUT
Factorial of 5 is: 120
 
RESULT
Thus, the Python program to find the factorial of a number was executed successfully.
